\# Kitchen Interior Business Website



A full-stack website for a Kitchen Interior Design business.



\## Tech Stack

\- Frontend: React.js (Vite)

\- Backend: Django + Django REST Framework

\- Database: MySQL

\- Image Storage: Cloudinary



\## Project Structure

\- `frontend/` — React customer website + admin dashboard

\- `backend/` — Django REST API
